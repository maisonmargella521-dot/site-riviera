# Волжская Ривьера

Лендинг базы отдыха с каталогом размещения, интерактивной формой бронирования и картой.

## Запуск

```bash
npm install
npm run dev
```

Заявки сохраняются в `localStorage` браузера (`riviera_bookings`). Форма проверяет пересечения дат для выбранного номера и не даёт создать повторную бронь. Страница `/admin.html` показывает собранные заявки и выгружает их в CSV, который открывается в Excel. Для продакшена обработчик формы можно заменить API-вызовом к CRM, Google Sheets или серверной базе данных.
